# Sunset City — Open-World Crime Game

A complete open-world crime game that plays offline in a desktop browser, built for the make.fun gta6-01 bounty ("Make GTA 6", $1,666).

Explore the sun-soaked city of Sunset City on foot and by car: steal cars, dodge traffic, outrun the police as your wanted level rises, take on missions, and build your reputation. All original — city, characters, story, art and sound.

Play it: open `game/index.html` in a desktop browser (no network needed), or serve it with `node serve.ts` and open http://localhost:8080.

Built with plain HTML, CSS and JavaScript (2D canvas). No build step, no network requests.
